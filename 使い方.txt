Event Studio — ブランドイベントタイマー

はじめに
  インストールして使う: EventStudio-<バージョン>-Setup.exe を実行して「インストール」を押します。デスクトップ
  またはスタートメニューの「Event Studio」から開きます。管理者権限もインターネット接続も不要です。
  インストールせずに使う: EventStudio.exe をそのまま実行しても使えます。
  「ブランド」タブで、ブランド名、イベント名、サブタイトルを入力します。
  空欄にした項目は画面で場所を取らず、その分タイマーが大きく表示されます。
  「画像を選択」で、ロゴ、パートナーロゴ、背景を入れられます。
  「ロゴの色」が「自動」なら、暗い画面で見えにくいロゴを白で表示します。「元の色」「白」に固定もできます。
  透明タイマーでは「白」を選んだときだけ白になります。
  設定パネルは下にスクロールできます。

言語（한국어 · English · 中文 · 日本語）
  編集画面の右上にある言語ボックスで 한국어、English、中文（簡体字）、日本語 のいずれかを選ぶと、
  画面の文字がすぐにその言語に変わります。透明タイマーと発表画面の案内
  （「まもなく終了」「発表時間」など）も一緒に変わります。
  選んだ言語は保存され、次に開いたときもそのままです。自分で入力したブランド名、イベント名、
  サブタイトルは変わりません。
  設定がまだないパソコンで初めて開くと、Windows の表示言語に合わせます（4 つの言語以外は英語）。
  インストール画面とアンインストール画面にも、右上に同じ言語ボックスがあります。スタートメニューの
  「使い方」と「アンインストール」のショートカット名は、インストール画面で選んだ言語になります。
  使い方ガイドは 4 つの言語すべてがインストールフォルダーに入ります
  （사용안내.txt、Guide.txt、使用说明.txt、使い方.txt）。

表示方式
  円グラフ / 棒グラフ / 数字 から選びます。進行中に切り替えても時間はそのままです。
  「時間·進行」タブで分と秒を直接入力するか、3・5・10・15・20 分を選びます。
  進行中に設定した発表時間は、リセット後に適用されます。
  下の −1分、−10秒、+10秒、+1分 は、進行中のタイマーにすぐ反映されます。

イベントの進行
  「開始」「一時停止」「再開」で時間を操作します。
  「発表後に Q&A を自動で開始」をオンにすると、発表が終わると質疑応答に移ります。
  「Q&Aへ切替」で早めに切り替えられ、残り時間を繰り越すかどうかも選べます。
  警告、終了の通知、超過時間、カウントアップ、秒単位の表示にも対応しています。
  「経過時間を表示（カウントアップ）」にすると、円グラフと棒グラフは減るのではなく、経過した分だけ
  埋まっていきます。

透明タイマー（背景なし、常に最前面）
  上の「透明タイマーを起動」ボタン（または「透明タイマー」タブ）を押すと、編集画面が背景のない
  小さなタイマーに変わり、画面の右上で、すべてのウィンドウの上に表示されます。
  全画面のスライドを表示していても、1 秒ごとに最前面に戻ります。
  マウスを乗せると、タイマーの上に リセット · 再開 · 一時停止 ボタンが表示されます。
    リセット: 最初の時間に戻して停止
    再開: 止めたところから続ける（最初は「開始」）
    一時停止: いったん止める
    歯車ボタン: 編集画面に戻る    X ボタン: アプリを終了
  マウスを離すか、3 秒間動かさないと、ボタンは消えます。
  タイマーをドラッグすると移動、クリックで開始/一時停止、右クリックでリセットです。
  右下の角をドラッグするか、Ctrl+マウスホイールでサイズを変えられます。
  ボタンを押しても、PowerPoint などの発表ソフトのキーボード操作はそのまま使えます。
  数字・円・バーのない何もない所をクリックすると、後ろのウィンドウがクリックされます。
  表示中は、タスクバーと Alt+Tab の一覧に表示されません
  （発表中にうっかりタイマーへ切り替えたり、最小化したりすることがありません）。
  編集画面に戻るにはタイマーにマウスを乗せて歯車ボタンを、終了するには X ボタンを押します。
  透明タイマーの背景は常に透明です。イベントの背景画像は、プレビュー・全画面・発表画面にだけ表示されます。
  「ブランド・イベント名・ロゴも表示」をオンにすると、タイマーの上にブランド名、イベント名、
  サブタイトル、ロゴが、背景なしの文字と画像だけで表示されます。ウィンドウを大きくすると文字も大きくなります。
  文字が見えにくいときだけ、「透明タイマー」タブで「暗い下地」を上げてください（0% は完全に透明）。
  「アプリを開いたら透明タイマーで開始」をオンにすると、次回から最初から透明タイマーで開きます。
  グローバルショートカットをオンにすると、ほかのプログラムを使っているときも
  Ctrl+Alt+Space 開始/一時停止、Ctrl+Alt+R リセット、Ctrl+Alt+Q Q&Aへ切替 が使えます。
  透明タイマーの表示中は、Ctrl+1 開始/一時停止、Ctrl+2 リセット、Ctrl+3 Q&A も使えます。

インストールファイル（ほかのパソコンにインストールする）
  上の「インストーラーを作成」ボタンを押すと、いま使っているプログラムを 1 つのインストールファイル
  （EventStudio-<バージョン>-Setup.exe）にまとめます。保存先を選ぶだけです。
  「現在のブランド・イベント設定と画像も一緒に入れる」をオンにしておくと、ブランド名、イベント名、
  ロゴ、背景、通知音、時間の設定も一緒に入り、インストール先のパソコンでもいまの画面のまま始まります。
  インストールファイルを会場のパソコンに移して実行し、「インストール」を押します。
  インストール先フォルダーは「参照...」で変更でき、デスクトップのショートカットとスタートメニューへの
  登録はオフにできます。
  そのパソコンに保存済みの設定がある場合は、そのまま残します。「インストールファイルの設定に置き換える」を
  オンにするとインストールファイルの設定に置き換え、以前の設定はインストールフォルダー内の
  previous-settings フォルダーに保管します。
  新しいバージョンは、同じフォルダーにもう一度インストールするだけです。タイマーが開いている場合は
  先に終了してください。
  インターネットで受け取ったインストールファイルを初めて開くときに、Windows が「Windows によって PC が
  保護されました」という画面を表示したら、「詳細情報」を押してから「実行」を押してください。
  署名のないプログラムには必ず表示される案内です。

アンインストール
  Windows の設定 > アプリ > インストールされているアプリ で「Event Studio」をアンインストールするか、
  スタートメニューの「Event Studio のアンインストール」を押します。設定と画像は、残すか一緒に削除するかを
  選べます。残しておくと、再インストールしたときにそのまま使えます。インストールフォルダーに自分で
  入れたほかのファイルは削除されません。

発表画面
  「発表画面を開く」で別ウィンドウを開き、プロジェクターやほかのモニターに移動します。
  そのウィンドウで F11 を押すと全画面、Esc でウィンドウ表示に戻ります。
  編集ウィンドウの「全画面」ボタンも使えます。

ショートカット（アプリのウィンドウが選択されているとき）
  Space  開始 / 一時停止
  1 / 2 / 3  円 / バー / 数字
  R  リセット（確認あり）
  Q  Q&Aへ切替（Q&A をオンにしている場合）
  F11  全画面
  Esc  全画面を終了
  文字の入力中は、タイマーのショートカットは動作しません。

ファイルと保存
  PNG、JPG、WebP、BMP の画像と、WAV/MP3 の終了通知音が使えます。
  画像は最大 40MB、縦横それぞれ 8192px まで対応しています。大きい画像はコピーするときに縮小されます
  （長辺：背景 3840px、ロゴ 2048px）。
  選んだ画像はこのアプリの assets フォルダーに PNG でコピーされ、元のファイルは変更されません。
  設定はアプリの隣の settings.json に自動で保存され、直前の内容は settings.backup.json に残ります。
  settings.json を読み込めないときは settings.backup.json にある直前の設定で開き、読み込めなかったファイルは
  次に保存するときに settings.unreadable.json として残します。
  プログラムを起動できないときや、問題が起きて終了するときは、メッセージが表示され、内容がアプリの隣の
  error-log.txt に記録されます。
  インストールした場合は、インストールフォルダー（通常は自分のアカウントの
  AppData\Local\Programs\Event Studio）がその場所です。
  インストールせずに使うときは、書き込みできるフォルダーで使ってください。エラーはウィンドウの下に表示されます。
  ブランドロゴや写真は、使用権のあるファイルを使ってください。

macOS で使うとき
  EventStudio-<バージョン>-macOS.dmg を開き、Event Studio を「アプリケーション」フォルダにドラッグします。
  インストール画面はありません。
  署名のないアプリなので、初めて開くときに macOS に止められたら、システム設定 > プライバシーとセキュリティ で
  「このまま開く」を押してください。
  設定、画像、error-log.txt はアプリの隣ではなく、~/Library/Application Support/Event Studio フォルダに保存されます。
  ショートカットの Ctrl は Control キー、Alt は Option キーです。全画面は Control+Command+F でも切り替えられます。
  透明タイマーをクリックすると Event Studio が一瞬前面に出て、マウスボタンを離すとキーボードは
  スライドソフトに戻ります。
  浮いている間も Event Studio は Dock に表示されます。
  「インストーラーを作成」は Windows だけの機能です。別の Mac ではアプリをそのままコピーして使えます。
  削除するときはアプリをゴミ箱に入れます。設定も消す場合は、上の Event Studio フォルダも削除してください。
