Event Studio — 브랜드 행사 타이머

시작하기
  설치해서 쓰기: EventStudio_Setup.exe를 실행하고 "설치"를 누르세요. 바탕 화면과 시작 메뉴의
  "Event Studio"로 엽니다. 관리자 권한이나 인터넷 연결은 필요하지 않습니다.
  설치 없이 쓰기: EventStudio.exe를 그대로 실행해도 됩니다.
  브랜드 · 이미지 탭에서 브랜드 이름, 행사명, 부제를 입력하세요.
  이미지 선택으로 로고, 파트너 로고와 배경을 넣을 수 있습니다.
  설정 패널은 아래로 스크롤할 수 있습니다.

언어 (한국어 · English · 中文 · 日本語)
  편집 화면 오른쪽 위의 언어 상자에서 한국어, English, 中文(간체), 日本語 중에 고르면 화면의 글이
  바로 그 언어로 바뀝니다. 투명 타이머와 발표 화면의 안내 글("곧 종료", "발표 시간" 등)도 함께 바뀝니다.
  고른 언어는 저장되어 다음에 열 때도 그대로입니다. 직접 입력한 브랜드 이름, 행사명, 부제는 바뀌지 않습니다.
  아무 설정도 없는 컴퓨터에서 처음 열면 Windows 표시 언어를 따릅니다 (네 언어가 아니면 영어).
  설치 창과 제거 창도 오른쪽 위에서 언어를 바꿀 수 있고, 시작 메뉴의 사용안내와 제거 바로 가기는
  설치 창에서 고른 언어로 이름이 붙습니다. 사용안내 문서는 네 언어 모두 설치 폴더에 들어갑니다
  (사용안내.txt, Guide.txt, 使用说明.txt, 使い方.txt).

표시 방식
  원그래프 / 막대그래프 / 숫자 중 선택하세요. 진행 중 바꿔도 시간은 유지됩니다.
  시간 · 진행 탭에서 분·초를 직접 입력하거나 3·5·10·15·20분을 고르세요.
  진행 중 설정한 발표 시간은 초기화 후 적용됩니다.
  하단 −1분, −10초, +10초, +1분은 현재 타이머에 바로 적용됩니다.

행사 진행
  시작하기와 일시정지, 이어하기로 시간을 제어하세요.
  Q&A 자동 시작을 켜면 발표 종료 후 질의응답으로 넘어갑니다.
  Q&A 전환 버튼으로 일찍 전환할 수 있고, 잔여시간 이월을 선택할 수 있습니다.
  주의 알림, 종료 알림, 초과시간, 카운트업, 초 단위 표시도 지원합니다.
  카운트업(경과시간 표시)으로 두면 원그래프·막대그래프는 줄어드는 대신 지난 만큼 채워집니다.

투명 타이머 (배경 없이 항상 맨 위)
  위쪽 "투명 타이머 실행" 버튼(또는 "투명 타이머" 탭)을 누르면 편집 화면이
  배경 없는 작은 타이머로 바뀌어 화면 오른쪽 위, 모든 창 위에 떠 있습니다.
  발표 슬라이드(전체 화면)를 띄워도 1초마다 다시 맨 위로 올라옵니다.
  마우스를 올리면 타이머 위에 리셋 · 재시작 · 멈춤 버튼이 나타납니다.
    리셋: 처음 시간으로 되돌리고 멈춤
    재시작: 멈춘 곳부터 이어서 진행 (처음에는 "시작")
    멈춤: 잠시 멈춤
    톱니 버튼: 편집 화면으로 돌아가기    X 버튼: 앱 종료
  마우스를 치우거나 3초 동안 움직이지 않으면 버튼이 사라집니다.
  타이머를 끌면 이동, 클릭하면 시작/멈춤, 오른쪽 클릭은 리셋입니다.
  오른쪽 아래 모서리를 끌거나 Ctrl+마우스 휠로 크기를 바꿉니다.
  버튼을 눌러도 파워포인트 같은 발표 프로그램의 키보드 입력은 그대로 유지됩니다.
  숫자·원·막대가 없는 빈 곳을 누르면 뒤에 있는 창이 눌립니다.
  떠 있는 동안에는 작업 표시줄과 Alt+Tab 목록에 나오지 않습니다
  (발표 중에 실수로 타이머로 넘어가거나 최소화되는 일이 없습니다).
  편집 화면으로 돌아오려면 타이머에 마우스를 올려 톱니 버튼을, 끝내려면 X 버튼을 누르세요.
  투명 타이머의 배경은 항상 투명합니다. 행사 배경 이미지는 미리보기·전체 화면·발표 화면에만 나옵니다.
  "브랜드 · 행사명 · 로고도 함께 표시"를 켜면 타이머 위쪽에 브랜드 이름, 행사명, 부제, 로고가
  배경 없이 글자와 그림만 나옵니다. 창을 키우면 글자도 함께 커집니다.
  글자가 잘 안 보일 때만 "투명 타이머" 탭에서 어두운 바탕을 올리세요 (0%면 완전히 투명).
  "앱을 열면 투명 타이머로 바로 시작"을 켜면 다음 실행부터 바로 떠 있는 타이머로 열립니다.
  전역 단축키를 켜면 다른 프로그램을 보고 있어도
  Ctrl+Alt+Space 시작/멈춤, Ctrl+Alt+R 리셋, Ctrl+Alt+Q Q&A 전환이 됩니다.
  투명 타이머가 떠 있을 때는 Ctrl+1 시작/멈춤, Ctrl+2 리셋, Ctrl+3 Q&A 도 됩니다.

설치 파일 (다른 컴퓨터에 설치하기)
  위쪽 "설치 파일 만들기" 버튼을 누르면 지금 쓰는 프로그램을 설치 파일 하나
  (EventStudio_Setup.exe)로 묶습니다. 저장할 곳만 고르면 됩니다.
  "지금 브랜드 · 행사 설정과 이미지도 함께 담기"를 켜 두면 브랜드 이름, 행사명, 로고, 배경,
  알림음, 시간 설정이 함께 들어가 설치한 컴퓨터에서 지금 화면 그대로 시작합니다.
  설치 파일을 행사장 컴퓨터로 옮겨 실행하고 "설치"를 누르세요. 설치 폴더는 "찾아보기..."로
  바꿀 수 있고, 바탕 화면 바로 가기와 시작 메뉴 등록은 끌 수 있습니다.
  그 컴퓨터에 이미 저장된 설정이 있으면 그대로 둡니다. "설치 파일에 담긴 설정으로 바꾸기"를
  켜면 설치 파일의 설정으로 바꾸고, 전의 설정은 설치 폴더의 previous-settings 폴더에 보관합니다.
  새 버전은 같은 폴더에 다시 설치하면 됩니다. 타이머가 켜져 있으면 먼저 끝내세요.
  인터넷으로 받은 설치 파일을 처음 열 때 Windows가 "PC 보호" 창을 띄우면 "추가 정보"를 누른 뒤
  "실행"을 누르세요. 서명이 없는 프로그램에 늘 나오는 안내입니다.

제거
  Windows 설정 > 앱 > 설치된 앱에서 "Event Studio"를 제거하거나, 시작 메뉴의 "Event Studio 제거"를
  누르세요. 설정과 이미지는 남겨 둘지 함께 지울지 고를 수 있습니다. 남겨 두면 다시 설치했을 때
  그대로 쓸 수 있습니다. 설치 폴더에 직접 넣어 둔 다른 파일은 지우지 않습니다.

관객용 화면
  발표 화면 열기로 별도 창을 열어 프로젝터/다른 모니터로 이동하세요.
  그 창에서 F11을 누르면 전체 화면, Esc는 창 모드로 돌아갑니다.
  편집 창의 전체 화면 버튼도 사용할 수 있습니다.

단축키 (앱 창이 선택되어 있을 때)
  Space  시작 / 일시정지
  1 / 2 / 3  원형 / 막대 / 숫자
  R  초기화 확인
  Q  Q&A 전환 (Q&A를 켠 경우)
  F11  전체 화면
  Esc  전체 화면 종료
  텍스트 입력 중에는 타이머 단축키가 작동하지 않습니다.

파일과 보관
  PNG, JPG, WebP, BMP 이미지, WAV/MP3 종료 알림음을 사용할 수 있습니다.
  이미지는 최대 40MB, 가로·세로 각각 8192px까지 지원합니다.
  선택한 이미지는 이 앱의 assets 폴더에 PNG로 복사되며 원본은 변경하지 않습니다.
  설정은 앱 옆 settings.json에 자동 저장되고 직전 값은 settings.backup.json에 남습니다.
  설치한 경우에는 설치 폴더(보통 내 계정의 AppData\Local\Programs\Event Studio)가 그 자리입니다.
  설치 없이 쓸 때는 쓰기 가능한 폴더에서 사용하세요. 오류는 창 아래에 표시됩니다.
  브랜드 로고와 사진은 사용 권한이 있는 파일을 넣어주세요.

검증 상태
  Rust 빌드 및 실행, 타이머·설정·이미지·투명 타이머 버튼·설치/제거·언어 자동 테스트 모두 통과.
  네 언어 모두 편집 화면, 투명 타이머, 설치 창을 실제로 그려 글자가 깨지거나 넘치지 않는지 확인.
  설치 파일 만들기 → 설치 → 설치된 프로그램 실행 → 다시 설치 → 제거까지 임시 폴더 안에서 실제 파일로 확인.
  (이 컴퓨터의 실제 시작 메뉴 · 바탕 화면 · 앱 목록에 설치하는 것은 사용자가 직접 실행할 때 처음 이루어집니다.)
  잠금이 풀린 실제 화면에서 원·막대·숫자 투명 타이머 모양과 빈 곳 클릭 통과, 버튼이 나타났다 사라지는 동작 확인.
  실제 원형·막대·숫자 창과 사용자 이미지 적용 화면 PNG 생성 확인.
  투명 타이머가 실제 화면에서 뒤 창이 비쳐 보이는 것과 클릭해도 앞의 창이 그대로인 것 확인.
