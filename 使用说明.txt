Event Studio — 品牌活动计时器

开始使用
  安装使用：运行 EventStudio_Setup.exe 并点击“安装”。通过桌面或开始菜单中的“Event Studio”打开。
  无需管理员权限，也无需联网。
  免安装使用：也可以直接运行 EventStudio.exe。
  在“品牌·图片”选项卡中输入品牌名称、活动名称和副标题。
  留空的项目不会占用画面位置，计时器会相应地显示得更大。
  通过“选择图片”可以放入标志、合作伙伴标志和背景。
  “标志颜色”为“自动”时，在深色画面上不易看清的标志会以白色显示；也可以固定为“原色”或“白色”。
  在悬浮计时器上，只有选择“白色”时标志才会变成白色。
  设置面板可以向下滚动。

语言（한국어 · English · 中文 · 日本語）
  在编辑界面右上角的语言框中选择 한국어、English、中文（简体）或 日本語，界面文字会立即切换。
  悬浮计时器和演示窗口中的提示文字（“即将结束”“演讲时间”等）也会一起切换。
  所选语言会被保存，下次打开时保持不变。您自己输入的品牌名称、活动名称和副标题不会改变。
  在还没有任何设置的电脑上首次打开时，会跟随 Windows 的显示语言（不是这四种语言时使用英语）。
  安装窗口和卸载窗口的右上角也有同样的语言框。开始菜单中“使用说明”和“卸载”快捷方式的名称，
  使用安装窗口中所选的语言。使用说明会以四种语言全部安装到安装文件夹中
  （사용안내.txt、Guide.txt、使用说明.txt、使い方.txt）。

显示方式
  可选择 环形图 / 条形图 / 数字。计时过程中切换也不会影响时间。
  在“时间·流程”选项卡中直接输入分和秒，或选择 3、5、10、15、20 分钟。
  计时过程中设定的演讲时间会在重置后生效。
  底部的 −1 分钟、−10 秒、+10 秒、+1 分钟会立即作用于当前计时。

活动进行
  用“开始”“暂停”“继续”控制时间。
  打开“演讲结束后自动开始问答”后，演讲结束时会进入问答环节。
  点击“切换到问答”可以提前切换，并可选择是否把剩余时间转入问答。
  还支持提醒、结束提示、超时显示、正计时以及以秒为单位显示。
  打开“显示已用时间（正计时）”后，环形图和条形图不再减少，而是随时间逐渐填满。

悬浮计时器（无背景，始终置顶）
  点击上方的“启动悬浮计时器”按钮（或使用“悬浮计时器”选项卡），编辑界面会变成没有背景的
  小计时器，显示在屏幕右上角、所有窗口之上。
  即使放映全屏幻灯片，它也会每秒重新回到最上层。
  将鼠标移到计时器上，会出现 重置 · 继续 · 暂停 按钮。
    重置：回到初始时间并停止
    继续：从暂停处继续（第一次显示为“开始”）
    暂停：暂时停止
    齿轮按钮：返回编辑界面    X 按钮：退出程序
  鼠标移开或 3 秒不动时，按钮会消失。
  拖动计时器可移动，单击开始/暂停，右键单击重置。
  拖动右下角或使用 Ctrl+鼠标滚轮可以调整大小。
  点击按钮不会抢走 PowerPoint 等演示软件的键盘输入。
  点击没有数字、圆环或条形的空白处时，点击会传给后面的窗口。
  悬浮期间不会出现在任务栏和 Alt+Tab 列表中
  （演讲过程中不会误切换到计时器，也不会把它最小化）。
  要返回编辑界面，请将鼠标移到计时器上并点击齿轮按钮；要退出，请点击 X 按钮。
  悬浮计时器的背景始终透明。活动背景图片只显示在预览、全屏和演示窗口中。
  打开“同时显示品牌、活动名称和标志”后，品牌名称、活动名称、副标题和标志会显示在计时器上方，
  只有文字和图片，没有背景。放大窗口时文字也会随之变大。
  只有在文字看不清时，才在“悬浮计时器”选项卡中调高“深色底衬”（0% 为完全透明）。
  打开“打开程序时直接以悬浮计时器启动”后，下次启动会直接以悬浮计时器打开。
  打开全局快捷键后，即使正在使用其他程序，也可以使用
  Ctrl+Alt+Space 开始/暂停、Ctrl+Alt+R 重置、Ctrl+Alt+Q 切换到问答。
  悬浮计时器显示时，还可以使用 Ctrl+1 开始/暂停、Ctrl+2 重置、Ctrl+3 问答。

安装文件（在其他电脑上安装）
  点击上方的“制作安装文件”按钮，可将正在使用的程序打包成一个安装文件
  （EventStudio_Setup.exe）。只需选择保存位置即可。
  打开“同时包含当前的品牌、活动设置和图片”后，品牌名称、活动名称、标志、背景、提示音和
  时间设置会一并打包，安装后的电脑会以当前画面的样子启动。
  把安装文件拿到活动现场的电脑上运行，并点击“安装”。可以用“浏览...”更改安装文件夹，
  也可以关闭桌面快捷方式和开始菜单项。
  如果那台电脑上已有保存的设置，会保持不变。勾选“替换为安装文件中的设置”后，会改用安装文件中的
  设置，原来的设置则保存在安装文件夹的 previous-settings 文件夹中。
  新版本只需再次安装到同一文件夹即可。如果计时器正在运行，请先关闭。
  首次打开从网上获得的安装文件时，如果 Windows 显示“Windows 已保护你的电脑”窗口，请点击
  “更多信息”，再点击“仍要运行”。所有未签名的程序都会出现这个提示。

卸载
  在 Windows 设置 > 应用 > 已安装的应用 中卸载“Event Studio”，或点击开始菜单中的
  “卸载 Event Studio”。可以选择保留或删除设置和图片。保留的话，重新安装后可以继续使用。
  您自己放进安装文件夹的其他文件不会被删除。

演示窗口
  点击“打开演示窗口”会打开一个独立窗口，请将它移到投影仪或其他显示器上。
  在该窗口中按 F11 进入全屏，按 Esc 返回窗口模式。
  也可以使用编辑窗口的“全屏”按钮。

快捷键（程序窗口处于选中状态时）
  Space  开始 / 暂停
  1 / 2 / 3  环形 / 条形 / 数字
  R  重置（会先确认）
  Q  切换到问答（已打开问答时）
  F11  全屏
  Esc  退出全屏
  输入文字时，计时器快捷键不起作用。

文件与保存
  可以使用 PNG、JPG、WebP、BMP 图片，以及 WAV/MP3 结束提示音。
  图片最大 40MB，宽和高各不超过 8192px。
  所选图片会以 PNG 格式复制到本程序的 assets 文件夹中，原文件不会被更改。
  设置会自动保存到程序旁边的 settings.json 中，上一次的内容保留在 settings.backup.json 中。
  如果无法读取 settings.json，程序会用 settings.backup.json 中上一次的设置打开；无法读取的文件会在下次保存时
  另存为 settings.unreadable.json。
  程序无法启动或因出现问题而关闭时，会弹出提示窗口，并把详细信息写入程序旁边的 error-log.txt。
  安装后，这个位置就是安装文件夹（通常是您账户下的 AppData\Local\Programs\Event Studio）。
  免安装使用时，请在可写入的文件夹中使用。错误信息会显示在窗口底部。
  品牌标志和照片请使用您有权使用的文件。

在 macOS 上使用
  打开 EventStudio-<版本>-macOS.dmg，把 Event Studio 拖到“应用程序”文件夹中。没有单独的安装窗口。
  这个应用没有签名，首次打开时如果 macOS 阻止，请在“系统设置 > 隐私与安全性”中点击“仍要打开”。
  设置、图片和 error-log.txt 不保存在应用旁边，而是保存在 ~/Library/Application Support/Event Studio 文件夹中。
  快捷键中的 Ctrl 是 Control 键，Alt 是 Option 键。也可以用 Control+Command+F 切换全屏。
  点击悬浮计时器时，Event Studio 会短暂地来到前面；松开鼠标按键后，键盘会交还给演示程序。
  悬浮期间，Event Studio 仍会显示在程序坞中。
  “制作安装文件”只在 Windows 上提供。要在另一台 Mac 上使用，直接复制应用即可。
  卸载时把应用移到废纸篓；如果也要删除设置，请同时删除上面的 Event Studio 文件夹。

验证情况
  Rust 构建与运行；计时器、设置、图片、悬浮计时器按钮、安装/卸载以及语言的自动测试全部通过。
  四种语言的编辑界面、悬浮计时器和安装窗口都实际绘制过，确认文字没有乱码或被截断。
  制作安装文件、安装、运行已安装的程序、再次安装、卸载，均在临时文件夹中用真实文件确认。
  （安装到这台电脑真实的开始菜单、桌面和应用列表，要等您亲自运行安装文件时才会第一次进行。）
  在已解锁的真实屏幕上确认了环形、条形、数字三种悬浮计时器的样子、空白处点击穿透，以及按钮的出现和消失。
  确认生成了真实的环形、条形、数字窗口以及应用用户图片后的画面 PNG。
  在真实屏幕上确认了悬浮计时器后面的窗口可以透出来，并且点击计时器后前面的窗口保持不变。
